# Offline Helper Sales Playbook (updated 2026-07-20)

## Positioning

Offline Helper is not “AI consulting.” It is patient, done-for-you setup for families who want a useful local-first AI helper without becoming technical — plus optional **Care Plan** retention and **hardware kits** that set offline depth and open-model class.

Core promise:

> “We make AI feel safe, private, and understandable on your own Mac or Windows PC — fit-check first, no pressure. Hardware only if you need deeper offline.”

## Fit-check script

1. Who is this for?
2. What computer? Mac/Windows, approximate year, memory if known.
3. First 1–3 useful jobs?
4. What feels risky? (privacy, cost, complexity, quality)
5. Who needs to approve?
6. How offline do they need to be? Soft / mostly / deep?
7. What would make week one clearly worth it?

## Close language

If fit:

> “This looks like a good Home / Family Care fit. I’ll send confirmed-fit checkout only now that we know goals, device, and boundaries. Hardware is optional — only if you want more offline depth than this machine allows.”

If not fit:

> “I don’t think taking payment would be fair yet. Here’s the safer path I’d recommend first.”
